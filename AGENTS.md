# Agent Rules

## UI & Screenshot Updates

- **Update screenshots on UI changes**: Whenever a UI change is made (in `ui/`) or a new feature is added that updates or introduces UI elements, update the corresponding screenshot(s) in `docs/screenshots/`.
- **Document new views**: If a new page, tab, or major UI view is added without an existing screenshot, capture a new screenshot in `docs/screenshots/` (using demo data, without real secrets or personal information) and add it to the `## Screenshots` table in `README.md`.
- **Keep theme variants in sync**: If a change affects a view that also has a dark-mode screenshot (such as `docs/screenshots/sites.png` and `docs/screenshots/sites-dark.png`), update both.
